# اسم فامیل

بازی چندنفره‌ی «اسم فامیل» روی گوشی. هر بازیکن با گوشی خودش وارد یک اتاق می‌شود، وقت محدود است و جواب خالی یا با حرف اشتباه امتیاز ندارد.

## اجرا

Node.js نسخه ۱۸ یا بالاتر لازم است. پکیج اضافه‌ای نصب نمی‌شود.

```bash
node server.js
```

آدرس چاپ‌شده را روی گوشی‌ها (همان وای‌فای) باز کنید. یک نفر اتاق می‌سازد و بقیه با کد چهار رقمی وارد می‌شوند. اگر ویندوز جلوی ورود را گرفت، پورت ۸۰۸۰ را در فایروال باز کنید.

## قوانین امتیاز

- جواب یکتا ۱۰ امتیاز، جواب تکراری ۵ امتیاز، اگر فقط یک نفر جواب داده باشد ۱۵ امتیاز.
- جواب خالی یا با حرف اشتباه امتیاز ندارد. در دسته «اشیا» چیزهای پلاستیکی یا مصنوعی پذیرفته نمی‌شود.
- کلمه‌ای که در دایره لغات فارسی نباشد امتیاز نمی‌گیرد، مگر همه‌ی بقیه آن را تأیید کنند.
- امتیاز یک جواب فقط با انصراف خود بازیکن یا رضایت همه‌ی بقیه حذف می‌شود و به هیچ حریفی منتقل نمی‌شود.

## فایل‌ها

- `index.html` رابط بازی
- `server.js` سرور اتاق‌ها و امتیازدهی
- `words.txt` دایره لغات فارسی (اختیاری؛ بدون آن فقط تشخیص ظاهری کلمه‌های ناقص فعال است)

## منبع دایره لغات

`words.txt` از لغت‌نامه‌ی [Lilak](https://github.com/b00f/lilak) ساخته شده است (حق نشر ۲۰۱۵ Mostafa Sedaghat Joo، مجوز Apache 2.0). جزئیات در فایل `NOTICE`.
